# Auth & errors 页面与组件

日期：2026-10-11。交付为桌面 Web 本地交互示例；认证、账户、权限、邮件发送与 HTTP 响应由消费项目提供。

## 设计来源与元素清单

遵循 [Design-rules](../Design-rules.md)、[Component-Specification](../Component-Specification.md)、[UI-PATTERNS](../UI-PATTERNS.md)、[UI-STATES](../UI-STATES.md) 与 [I18N](../I18N.md)。不复制外部模板；采用现有组件 API。统一展示与独立页面是呈现交付，本文件是设计规格。

| 元素 | 实际来源 | 处理 |
| --- | --- | --- |
| 品牌、分栏、页脚、页面导航 | 新增 `AuthPageShell` | 公共布局；品牌和辅助内容由调用方提供 |
| 标题、说明、姓名、邮箱、密码、确认密码 | `AuthForm` + 现有 `Field` / `Input` | 新增受控表单模式，原生自动填充，密码显隐与提交校验 |
| 记住登录、接受条款 | 现有 Base UI `Checkbox` | 值受控，不持久化凭据 |
| 提交、重试、显隐、页面链接 | 现有 `Button` / `buttonVariants` | 按钮为动作、链接为导航；显隐有标签与提示 |
| 校验、等待、成功、失败、未知反馈 | 现有 `Alert` | 提交中防重复；失败保留草稿；未知状态锁定重提 |
| HTTP 状态码、解释、恢复动作 | 新增 `ErrorPage` | 401/403/404/500/503 文案、图标和恢复动作分别配置 |
| 全元素并排展示 | 新增 `AuthPageGallery` / `AuthPagePreview` | 同时挂载三个表单与五个错误页，非单项选择器 |
| 主题与语言 | 现有 ThemeProvider / LocaleSwitcher / I18nProvider | 页面适配器控制；不重挂表单、不触发提交 |

已采用：Next 16.3.8、React 19.3、TypeScript 6、Tailwind 4.3、Base UI 1.8、Lucide 0.577、CSS Modules、现有共享 tokens。源自仓库公开组件及已安装依赖；Base UI、Lucide 的 MIT 归属沿用仓库记录。未新增依赖；没有采用或计划安装认证 SDK。路由静态导出；文档演示通过显式 loader 懒加载，完整页面仅装载当前模式；总览按契约同时挂载全部元素。

## 模块声明

### AE-M01：公共页面骨架

由 `AuthPageShell` 承担品牌、工具栏、左右分栏或居中错误内容和页脚；接收 ReactNode slots，不依赖 Next、文档站或网络。背景/文字/分隔使用共享 background、surface、muted-foreground、border tokens，32px 外边距，4px 网格，细边框、无主体阴影。完整页面有一个 h1，预览使用 h2。品牌辅助标题 32px、错误码 96px 属认证/空态展示的局部例外，不改变工具页标题或公共控件 32px 基线。导航有独立 focus ring，hover 只加在动作上。

### AE-M02：AuthForm

组件 hydration 就绪前原生 fieldset 禁用，防止快速输入丢失或浏览器原生提交携带凭据；就绪后才接受输入与 Enter 提交。等待文字复用 typed messages，语言切换不重置就绪状态。

host：AE-P01–04。受控 `mode/value/onChange/onSubmit/feedback`；值包含姓名、邮箱、密码、确认密码、记住登录与条款布尔值。标题 24/32，说明 13/20，字段间 16px，控件 32px，统一 6px control 圆角；密码显隐按钮与输入为兄弟，输入保留同一 DOM。提交校验空值/邮箱/最短密码/确认密码/条款；错误关联字段，焦点转到首个错误。登录不强加注册最短密码限制。Enter 提交，Checkbox Space 切换，显隐不提交。`submitting/success/unknown` 锁定提交；`error` 保留草稿并允许显式重试；未知由调用方查询后传入新的权威反馈。缺少回调时禁用提交。成功文案由调用方提供，不把回调或计时器视为服务证据。用户内容与协议字段不翻译，组件文字用 typed messages。条款内容由 caller slot 提供；演示有可打开的本地条款说明。

### AE-M03：ErrorPage

错误码使用可读的 muted-foreground，不降低透明度；大文字的对比度也纳入双主题验收。

host：AE-P01/05–09。受控 code、actions、retry/busy/feedback/requestId；不读取权限、不自动重试、不显示真实诊断堆栈。401 提示登录缺失/失效；403 提示权限不足；404 提示地址或资源变化；500 提示原因未确认；503 提示服务暂不可用，维护原因只有调用方提供时显示。恢复动作与状态对应，重试仅由调用方显式提供；重试过程中保留整页说明且防重复。错误码为装饰性大数字，语义码另有可读文本；正文 14/24，操作间 8px，主操作最多一个。长反馈换行，鼠标/键盘、双主题与减少动效可用。

### AE-M04：元素展示

host：AE-P01 与 `/docs/auth-pages/`。公共 Gallery/Preview 布局接收真实子组件和链接，无存储与服务；总览适配器提供成功/拒绝/未知结果演示选择，反馈明确标注本地演示。开发说明包含技术、来源、组件映射和服务边界。每个面板独立状态；选择反馈场景不丢弃输入，不向网络写入。预览标题与表单标题有合理 heading 层级。
