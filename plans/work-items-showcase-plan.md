## 1. 页面目标与范围

入口 `/workspace/work-items/`，用同一组确定性本地工作项展示 List、Board、Table、Timeline、Calendar，验证组件在完整工作台中的组合、状态恢复、响应式和无障碍。

参考 Plane 的工作项信息架构，视觉遵循 EasyuseUI 的紧凑中性设计，不承诺逐像素复制 Plane。不会修改 Plane 项目、连接其真实工作区或把本地交互当作真实任务服务。

页面使用配套计划的公开组件和现有 WorkspaceShell、DataRegion、Inspector/Sheet。页面不重写卡片、行、属性选择器、分组和拖放实现。

## 2. 页面结构

```text
WorkspaceShell
├─ Sidebar：示例项目 / Work Items / 返回文档
├─ Header：项目 / Work Items                      新建
├─ Toolbar：[List | Board | Table | Timeline | Calendar] 搜索 筛选 显示
├─ AppliedFilters：负责人 ×  优先级 ×       清除
├─ Main：WorkItemList / WorkItemBoard / WorkItemTable / WorkItemTimeline / WorkItemCalendar
├─ Inspector：当前工作项摘要与字段编辑
└─ 可折叠示例说明：数据来源 / 重置 / 场景切换 / 文档链接

浮层：QuickCreate、属性编辑、显示设置、移动到、窄屏详情
```

新建为页面主操作，布局/筛选/显示使用次级或轻量操作。场景开关收进说明区；不得把测试控制台作为工作项主界面。

| 展示模式 | 默认布局 | 用户能完成的任务 |
| --- | --- | --- |
| List | 按状态分组的紧凑行、组头计数/折叠/新增 | 快速扫描、选择、编辑字段、打开详情 |
| Board | 按状态分列，320px初始列宽，中性卡片 | 看流程分布、组内新增、移动状态、手动重排 |
| Table | DataTable，编号/标题/状态/优先级/负责人/标签/日期 | 对齐比较、选择和字段查看/编辑；排序由适配层提供 |
| Timeline | 固定侧栏、周/月/季度时间轴、44px行与24px日期条 | 平移或调整区间、表单精确修改、安排未排期项、独立手动排序 |
| Calendar | 月/周日期格与当日Agenda | 按截止日扫描、每日分页、只改截止日、预填新建草稿、安排已有项 |

五种布局共享同一数据源。当前工作项、筛选、底层数据及已提交字段保持一致。每种布局单独记住滚动位置，切换后明确恢复焦点。

## 3. 路由与视图状态

建议可分享参数：

```text
/workspace/work-items/?layout=list
/workspace/work-items/?layout=board&group=state
/workspace/work-items/?layout=table&item=wi-012
/workspace/work-items/?layout=timeline&scale=quarter&timelineDate=2026-10-09
/workspace/work-items/?layout=calendar&mode=week&calendarDate=2026-10-09
```

- 路由适配层持有 layout、group、sort、q、已支持的过滤条件和 item；公共组件不读取 Next 路由。
- query `item` 映射稳定示例实体 ID，不依赖可修改标题。无效 layout/group 回退受支持默认；无效 item 显示未找到并允许关闭。
- 使用显式编解码与参数白名单，字段值不通过翻译文本存储；设置变更采用replace，打开详情等明确导航采用push，浏览器后退可返回之前上下文。
- 未挂载/未解析URL前不写默认值覆盖传入参数；处理静态导出的客户端查询与必要Suspense边界，避免hydration后重置页面。
- localStorage仅可保存示例布局偏好，URL优先；查询、工作项、用户草稿和未知写结果不擅自持久化。刷新重置内存数据的说明始终可找到。
- SiteFrame仅对该工作台路径增加全窗口规则，保留其他路由行为与可达的文档返回入口。

## 4. 确定性数据与场景

建议基础fixture含24条工作项、5个示例工作流状态、4个优先级、若干负责人/标签。状态名称与数量可配置，不能固化进公共组件。日期、随机种子、时区和排序键固定以支持截图。

| 场景 | 内容与预期 |
| --- | --- |
| 正常项目 | 跨组工作项、长标题、多标签、多负责人、无负责人、无日期 |
| 数据空 | 项目无工作项，可新建；与筛选无匹配分开 |
| 筛选无匹配 | 保留原数据，清除筛选后恢复 |
| 分组部分加载 | 某组有总数但只载入一部分，支持加载更多；总数未知时显示已加载数 |
| 刷新失败 | 同对象旧数据保留，错误/过期提示与重试明确 |
| 只读项目 | 允许浏览/筛选/查看；禁用创建、字段修改和移动，解释原因 |
| 明确拒绝 | 字段或移动被fixture拒绝，保留草稿/恢复位置，可安全重试 |
| 写入结果未知 | 请求可能已生效，相关项显示待确认；先查询再决定下一操作 |
| 关联Agent | 工作项业务状态独立；额外显示真实标为模拟的RuntimeStatus |
| 压力数据 | 50/200/1000条，独立性能fixture，记录实际已渲染与已加载数量 |

不同场景通过示例适配器注入，不在公共组件中写入演示计时器。切换场景终止或丢弃旧generation的异步返回，避免污染新数据。统计直接来自当前fixture，不写固定成功数量。

## 5. 主要交互展示

### 5.1 筛选、分组与显示

- 首版支持标题/编号搜索，状态、优先级、负责人、标签筛选；同字段多选按OR，不同字段按AND，规则在UI说明和测试中一致。
- 已应用条件用可移除Chip，支持清除全部；0项结果不清掉查询条件。
- 分组首版支持状态、优先级；负责人/标签多值分组若展示则只读，禁止未定义集合语义的拖放。
- 显示设置包括分组、排序、字段显隐、空组；二级分组/子项开关到增强阶段才出现。
- 自动排序与手动排序互斥；进入自动排序时明确列内拖动不可用。改变布局不静默更改group或filters；不支持的配置可提示并保留为该布局偏好。

### 5.2 选择、详情与创建

- 行勾选与打开详情分别操作，切换视图保留selectedIds和activeItemId。隐藏选中项显示数量，提供显式清除；首版不提供无实现的批量写按钮。
- 点击主标题打开同一对象详情，桌面复用Inspector，窄屏用Shell已有抽屉；主链接保留可复制/新窗口访问的页面URL。
- 详情首版包含标题、编号、状态、优先级、负责人、标签和日期；描述展示或简单文本编辑即可，不以完整富文本编辑器/评论服务为前置。
- QuickCreate保留所属组预设，创建前验证组是否可写；失败保留标题草稿，提交中防重复。ID与编号由适配器确定，不在组件里猜测服务端编号。
- 创建后若不满足当前筛选，提示“已添加到示例，当前筛选下不可见”，提供查看/调整筛选动作，不直接改变用户查询。

### 5.3 Board移动与恢复

- 同列手动排序、跨状态列移动、空列移动分别演示；鼠标、触摸和键盘“移动到”共用命令。
- 成功后List/Table、详情、组计数同步；drag preview期间不提前展示“已保存”。
- 明确拒绝恢复，unknown先查询；通过卸载面板、切布局或语言切换不能清除未知结果限制。
- 权限在拖动中变化、并发版本变化、目标组折叠/被删除、拖动中切场景均有终止路径，不能写入错误对象。
- 分页未加载区域不得通过DOM索引推断全局位置；只演示可确定邻居或显式追加的落点。

## 8. 验收与效果展示

- 主流程：List创建并编辑工作项 → Board移动到新状态 → Table核对字段 → 返回List定位同一对象。
- 失败流程：写入未知 → 切布局仍待确认 → 查询结果 → 按确认状态解除限制；明确拒绝与读取错误不混为同类。
- URL流程：直接打开Board/详情 → 筛选 → 前进/后退 → 刷新，保留可分享配置并正确处理无效值。
- 数据流程：加载更多、重复/迟到响应、总数未知、刷新失败、空组、筛选无匹配和隐藏选择。
- 视觉：1440×1000、1024×768、390×844，深浅主题、中英文；List长行、Card长标题、多标签和负责人溢出有截图。
- 无障碍：Tab顺序、方向键选择、Escape逐层关闭、触屏移动替代、焦点恢复、reduced-motion、读屏名称；不嵌套交互元素。
- 性能：50/200/1000项固定场景，记录选择、切布局、分组、移动延迟及DOM数量；实测后制定门槛，不用不可见占位数量冒充渲染能力。
- 工程：lint、typecheck、build、check:i18n、check:manifest、适用浏览器测试；公共组件变更test:install。文章修改运行check:blog。先检查进程/端口，使用Webpack并保留共享工作。

Blog增加“Work Items的List、Board与Table如何共享组件”文章，展示三视图、属性复用、拖动恢复和移动端效果。Plane截图与EasyuseUI截图标明不同设计体系；未知/未测指标显示待测，模拟运行不冒充真实服务证据。

完成标准：配套W0–W4组件可安装，页面S0–S4主流程和失败流程通过，现有Workspace/Canvas/CRM相关组件无回归，文档有真实效果与限制说明。真实Plane接入、生产工作流及服务端保存视图属于后续接入范围。
