## 场景、视口与交互

- 57 个白名单场景：9 通用场景与 48 区域场景。10 个区域分别覆盖初始加载、空、部分、错误保留与成功；引用/连接/运行/回执等轴独立表达。
- 布局视口：1440×900、1280×800、1024×768、768×1024、390×844；另覆盖有效 200% 布局、粗指针、reduced-motion、英文、深浅主题、键盘与焦点恢复。
- 场景/项目 URL 与前进后退；快速连续导航保留最近选择，迟到创建确认不抢当前会话。
- 上下文重试等待回执，移除/替换后旧确认不能插入引用；包含选择改变不丢弃原来源确认。
- 计划定位具体工具，产物定位实际来源消息。可用/未知/拒绝/格式不支持决定预览与下载；下载检查实际报告字节。
- 空项目、筛选无结果和未选当前项目会话分别呈现；环境详情不借用其他项目会话。
- 只保存语言、主题与有界面板开关/尺寸；存储异常降级。清除偏好保留草稿，刷新重置业务 fixture。

## 首轮失败与修正

- 上下文重试原来立即变为可用，现等待独立来源回执；版本/移除/包含切换均验证。
- 快速选择项目后跳转会被旧 query 覆盖，现用最新导航快照；迟到创建确认按页面/会话保护。
- 小高度触摸视口中长环境按钮挤压输入区，改为有名称的图标操作并复测。
- 新环境详情检查揭示 Project 自定义 header 不渲染会话 header actions；项目正文增加所属项目环境详情入口。状态过滤区分无匹配，产物页阻止借用其他项目报告。
- 首轮全站 670 项中 669 通过，文档搜索读取失败时切换两个 Dialog 导致关闭。站点适配层改成单一 Dialog 内的 inline CommandPalette，保留错误、查询、显式重试与目录回退；原失败断言保留并加强查询保留检查，最终完整套件复测通过。
- 随后的 673 项中 672 通过，剩余断言发现站点重试按钮被公共组件标签替换；站点 footer 恢复原有“重试”动作与显式 attempt，再独立通过 35 项文档/首页检查并完成全量复测。
- 冷加载全量复测仍有 1 项搜索检查失败；trace 中首次点击后没有加载搜索模块或请求索引。搜索入口在 hydration 完成前保持 disabled，新增延迟 layout 脚本的浏览器检查验证首个有效点击；错误与恢复断言保持原要求。
- 场景/角色与焦点目标断言按实际公共组件合同修正；未放宽操作回执、来源版本或重复写入保护。

## 服务边界与已知限制

本轮没有接入模型、文件写入、Git、PTY、浏览器控制、鉴权与业务持久化，这些是组件计划 M6 的独立来源验收。页面日志/测试结果/报告正文为本地 fixture；来源“通过/失败”不代表本项目测试结果。64 张图记录初始场景，其余状态由动作与模型检查覆盖。

页面偏好不持久化草稿、会话、附件或凭据。刷新不恢复执行；关闭面板不停止任务；unknown 不表示成功，也不会自动重试写入。审阅状态与业务验收分列。
