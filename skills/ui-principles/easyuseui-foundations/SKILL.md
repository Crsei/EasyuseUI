# 基础样式与视觉层级

优先清晰、一致、高效，再处理精致与装饰。先确定信息层级，再选择视觉参数。

## 使用模式与规则优先级

- **使用 EasyuseUI 组件：** 先在库根目录读 `Design-rules.md`，再读 `Component-Specification.md`；共享值只从 `styles/theme.css` 获取。消费项目使用实际安装的主题与组件，不在页面复制常量。
- **不使用 EasyuseUI 组件：** 使用本技能的原则和数值基线，通过目标项目的 token、CSS 或设计系统表达。保留已有正式主题与用户明确风格要求，不要求 React、Tailwind、Lucide 或本库变量名。

本仓库默认复用；外部无本库依赖且未要求采用时默认独立实现。独立实现中的数值是起点，若目标项目已有契约则映射并说明差异；用户明确的例外优先。复用模式契约与 token 冲突时同步修订来源，不在单页发明替代体系。

## 构建顺序

Foundation → Primitive Components → Product Patterns → Workspace Layout → Page。先梳理现有 token 和组件，再补缺口；不绕过公共层为每页创建独立语言。

信息层级依次使用字号、字重、间距、对齐、背景和分隔线，再考虑颜色。Session、Agent、Activity、日志优先平铺 Item/List/Table；独立摘要、指标或预览才考虑 Card。

## 紧凑工作台基线

下表在 EasyuseUI 复用模式中是契约摘要，在独立实现中是可迁移基线。所有数值为 CSS px。

| 维度   | 基线                                                                |
| ------ | ------------------------------------------------------------------- |
| 间距   | 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64；6 仅图标文字光学校正 |
| 控件   | Button/Input 默认32；Button sm28、lg36；工具栏40                    |
| 行     | Item compact32、default40、双行56；同类区域使用一致密度             |
| 字体   | 正文14/20；长消息14/24；次级13/20；元信息12/16，数值等宽            |
| 标题   | Section16/24；工具页20/28，最高24/32                                |
| 字重   | 400 / 500 / 600，避免把所有字段加粗                                 |
| 圆角   | tiny4、control6、popover8、panel12、floating16；内部小于外部        |
| 边框   | 1px hairline；选中指示可用2px，不挤动内容                           |
| 焦点   | 可见2px ring，offset2或紧凑列表 inset；不被父容器裁切               |
| 图标   | 默认16、分区18、空态20；统一图标库及线宽；本库使用 Lucide 1.75      |
| 粗指针 | 交互控件、行、图标操作实际命中至少44×44；区域不能重叠               |

只读标签不强制扩大为44px。触摸目标通过真实布局留出空间，不以重叠伪元素或负 margin 假扩大。

## 颜色与表面

以中性背景、表面、细分隔线建立主体；强调色表达主操作、选中或焦点；状态使用文字/图标与颜色共同表达。不要整行染红表示某个工具失败，不用 AI 身份色覆盖运行状态。

复用模式采用现有 `background`、`surface`、`surface-raised`、`border`、`foreground`、`text-secondary`、`text-muted`、`primary` 等语义 token；运行颜色由统一运行字典映射。独立实现定义对应角色即可，不复制本库十六进制色值作为另一份真相。

先间距，再背景，再边框，最后阴影。常驻列表/主面板无需投影；Dialog、Popover 等浮层可以使用一致的浮层阴影。阴影 token 存在不代表同名组件或 Tailwind utility 存在。

## 动效与可访问性

动效只表达状态、空间、层级和因果关系，可中断。基线为 hover150ms、Button180ms、Popover200ms、Panel220ms、Drawer250ms、Layout300ms，ease-out；resize 拖动时不加 transition。减少动态效果时去除非必要旋转、闪烁和位移，仍保留文字状态。

静态信息不加 hover。选中持续表达当前对象，focus 表达键盘位置，两者可同时存在。图标操作有可访问名称和 hover/focus 解释；重要动作不能只在 hover 或右键中出现。

## 样式实验

比较参数时使用相同内容、值和交互状态；优先每次改变一个维度，并检查长内容、深浅主题、键盘和触屏。

- 复用模式可使用 `StyleWorkbench`，按 `STYLE-WORKBENCH.md` 核对 API 与参数；实验限制在预览容器，不能自动改根主题。
- 独立实现使用目标项目的预览工具或局部 CSS；保持基准和实验分离，不要求安装样式工作台。

实验参数成为产品默认前需明确采用，修订正式契约和共享 token，再验证受影响组件。样式对比通过不能证明数据、运行或服务集成通过。

## 交付检查

说明采用的使用模式、token 来源、关键参数及例外；检查页面能识别主任务、当前对象、重要状态和下一步。确认紧凑布局未牺牲触摸、焦点、文字可读性及长内容。只改说明文档时验证文档；实际修改组件时执行目标仓库规定的工程和行为检查。
