# 信息架构与交互模式

从用户要完成的任务选择模式，再选择组件。模式描述职责和交互，可以由不同技术栈实现。

## 使用模式

- **使用 EasyuseUI 组件：** 在库根目录先读 `Design-rules.md`、`Component-Specification.md`，再按需读 `UI-PATTERNS.md`；核对实际安装版本后复用行、树、数据区域和工作台。Popover、Tabs、Menu 等术语并不承诺独立 API。
- **不使用 EasyuseUI 组件：** 保留本技能的信息职责、选择与执行分离、渐进披露和恢复原则，用目标项目现有组件实现。数值以目标正式契约为准，不要求本库路径、Registry、框架或本机端口。

本仓库默认复用；外部项目未安装或未要求本库时默认独立实现。保留已有 URL、权限、业务对象关系和持久化语义；视觉调整不授权改变这些语义。

## 从任务选择模式

| 用户要做什么         | 模式                            | 边界                                         |
| -------------------- | ------------------------------- | -------------------------------------------- |
| 去另一个产品区域     | Sidebar / Navigation Link       | 稳定入口，保留 URL 与返回语义                |
| 看同一对象的其他面板 | Tabs                            | 对应内容面板与完整键盘行为，不代替全局导航   |
| 修改一个互斥值       | Radio Group / Segmented Control | 这是选值，非页面切换                         |
| 选一个对象并连续检查 | Master–Detail + Inspector       | 列表保留上下文，选择不执行运行操作           |
| 扫描同类对象         | Item / List                     | 状态与元信息可扫读，主目标与尾部操作是兄弟   |
| 比较固定字段         | Table / 对齐列                  | 未知值显示“—”，不为只读表引入复杂 grid 模型  |
| 浏览真实父子关系     | Tree                            | 默认单选；完整键盘模型与受控移动             |
| 查看活动过程         | Activity Timeline               | 按稳定 ID 去重，保留来源顺序                 |
| 阅读沟通与产物       | Conversation + Workspace        | 文件、Diff、Terminal、Preview 与消息职责分开 |
| 检查工具参数和输出   | Tool Call / Disclosure          | 摘要与证据分层，审批与未知结果持续可见       |
| 执行对象动作         | Button / Menu                   | 显式能力回调；高频可见，次要收起             |
| 选择字段值           | Select / Combobox               | 不把选值器当动作菜单                         |
| 专注小任务/确认范围  | Dialog                          | 标题、退出、焦点约束与明确完成入口           |
| 窄屏展示导航或详情   | Drawer / Sheet                  | 只改变呈现方式，不改变内容职责               |

## 分配信息职责

| 层级               | 回答的问题               | 放什么                                    |
| ------------------ | ------------------------ | ----------------------------------------- |
| 全局导航           | 我要去哪里？             | Projects、Sessions、Agents 等稳定入口     |
| 页面标题与 Toolbar | 当前区域能做什么？       | 搜索、筛选、排序、视图和页面动作          |
| 主工作区           | 我正在做什么？           | 当前任务、对象列表、Conversation、Runtime |
| Inspector          | 选中的对象是什么？       | 标题、状态、属性、关联文件和对象动作      |
| 证据详情           | 为什么，原始结果是什么？ | 参数、输出、Trace、回执和关联 ID          |

页面区最多一个 Primary，另有少量 Secondary。更多动作按上下文收起，但键盘/触摸也能发现。Inspector 不成为第二个列表或存储；原始 JSON 不替代可理解摘要。

## 工作台与响应式

复用模式使用 `WorkspaceShell` 承担布局、停靠/浮层、resize 和焦点，`Inspector` 承担受控详情。独立实现可采用同样职责拆分，使用目标项目布局组件。

EasyuseUI 基线：Sidebar256/收起48；Inspector 在可用容器宽≥1280时停靠，默认320、范围300–360；中等宽覆盖；<768时宽 `min(360px, viewport−32px)`。底部面板默认240、范围200–400。独立实现根据目标布局调整，不能为了维持三栏把主内容压到不可用。

浮层需要可达关闭动作、Escape、背景交互约束及焦点恢复；分隔条支持指针和键盘。隐藏导航标题保留可访问名称。对象切换时由调用方按对象 ID 丢弃迟到响应，不能在 B 标题下展示 A 属性。

## 渐进披露与长内容

首层保留身份、状态、等待原因、失败摘要、批准范围和未知结果；大参数、输出、次要属性按需展开。展开、选中和关闭只改变展示，不批准、不启动、不取消。

对话与活动在距底部≤64px时跟随新内容；用户向上阅读时保留位置并显示返回最新入口；补载历史保留锚点。流式反馈按阶段播报，不逐 token 抢读屏。工具预览有界，EasyuseUI 基线200行/32KiB，来源截断与本地预览截断明确区分。

## 数据、权限与动作

每个数据区域设计 loading/empty/partial/error/success；刷新保留旧数据，失败说明过期和更新时间。未创建、筛选无结果、未选择、无权限、读取失败分别表达。

只有调用方提供真实能力时才提供动作。启动、批准、取消等提交后显示等待来源确认；超时/响应丢失先对账再决定是否重试写入。纯本地展示状态可以立即更新；真实业务乐观更新需调用方有回滚/对账策略。

## 交付

实现前用简短说明固定任务、信息归属、选用模式、能力和状态恢复；复用模式补实际组件映射，独立实现补目标库映射。复杂任务可画简图，简单任务不强制制作额外文档。验收应能回答“我在哪、选了谁、它现在怎样、下一步能做什么”，并实际走通键盘、窄屏和恢复路径。
