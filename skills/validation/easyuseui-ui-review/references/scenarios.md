# 按组件选取的验收场景

只选择本次改动实际涉及的场景。涉及真实写入时使用已获授权的环境；本地fixture结果单独记录，不自动接入生产。

## 交互与布局

| 场景                       | 验收结果                                                      |
| -------------------------- | ------------------------------------------------------------- |
| Tab到图标按钮并激活        | 有可访问名称、focus解释、可见焦点；Enter/Space正确激活        |
| 已选中行再聚焦另一行       | selection与focus独立，焦点不会隐式执行运行操作                |
| 点击行尾动作               | 不顺便触发行主选择；DOM无嵌套button/link目标                  |
| 粗指针操作行与尾部按钮     | 真实命中至少44×44，目标不重叠，不依赖hover才能操作            |
| 窄屏打开详情，再Escape关闭 | 标题/关闭可达，背景不能误操作，焦点回合理触发处               |
| 键盘调整Inspector宽度      | separator可聚焦，边界和值可读；本库←→步长8，Home/End到300/360 |
| 长名称、ID、URL及大段输出  | 正文可读，省略有完整值入口，不制造整页横向滚动                |
| reduced-motion开启         | 状态仍明确，不依赖旋转/位移理解，基本任务可完成               |

## 状态、并发与消息

| 场景                         | 验收结果                                     |
| ---------------------------- | -------------------------------------------- |
| 首次读取无内容               | 骨架符合最终结构，不显示空态或假可点击行     |
| 当前筛选无结果               | 明确是筛选范围为空，动作指向调整筛选         |
| 有内容时刷新失败             | 内容保留，错误/过期/更新时间可见，可安全重读 |
| partial与未知数值            | 说明未完整范围，缺失为“—”，0仅表示实际零     |
| running同时详情读取失败      | runtime保留running，读取错误单独表达         |
| 选B后A响应迟到               | A响应被丢弃，B标题和字段始终同对象           |
| 重复事件到达                 | 稳定ID去重并保留来源顺序，不按渲染时间重排   |
| 距底部>64px时新增内容        | 保留阅读位置，出现新内容入口；≤64px可跟随    |
| 补载旧历史                   | 保留阅读锚点，不跳走                         |
| 中文输入法Enter、Shift+Enter | 组合期间不发送，Shift+Enter换行              |
| 消息提交失败/接收中断        | 草稿和已收文本保留，能力允许才显示重试/继续  |

## Tree与可操作值

| 场景                       | 验收结果                                                    |
| -------------------------- | ----------------------------------------------------------- |
| 方向键、Home/End、前缀定位 | 单一roving tab stop，访问可见节点；折叠含焦点分支后回父节点 |
| 子级读取失败/未完整        | 父节点和已有子级保留，有说明和真实恢复入口                  |
| 拖动到自身、后代或禁用目标 | 禁止无效落点；Esc取消；无能力不显示拖拽手柄                 |
| 键盘“移动到”               | 与拖拽调用同一受控移动能力，业务确认前不宣称持久化成功      |
| Chip选择与移除             | 两个兄弟目标；busy/disabled均防操作；移除后焦点合理恢复     |

## 工具、权限与未知结果

| 场景                                    | 验收结果                                                       |
| --------------------------------------- | -------------------------------------------------------------- |
| 展开待批准工具                          | 只展开；范围和风险可读，未发生批准或执行                       |
| 批准/取消回调resolve，来源未更新        | 显示请求已提交待确认，不直接completed/cancelled                |
| 写请求响应丢失                          | 保留ID/receipt与最后状态，显示结果未确认，只提供查询等安全路径 |
| 详情重读成功                            | 仅更新详情，不自动重新执行工具                                 |
| unknown后重新挂载                       | 调用方仍保留unknown，不能复位绕过对账                          |
| 未知runtime字符串、空输出、缺失exitCode | 原始未知值可诊断，空输出说明事实，不补绿色成功或退出码0        |
| 参数/错误/输出含凭据                    | 界面、复制、导出均脱敏，业务特殊凭据不泄漏                     |
| 输出超过200行/32KiB或来源截断           | 本库预览有界，明确截断性质；无完整源数据不提供假完整下载       |

## Canvas

- 空图通过点击/键盘表单构建 Input → Agent → Tool → Output；插边作为一次事务，失败保留原边，撤销/重做恢复拓扑。
- 拖动结束只提交一次；批量复制重新分配ID，内部引用重映射，外部变量引用明确拒绝。
- 配置无效JSON/数字保留草稿；切换对象与收起Inspector后可恢复；应用与放弃有不同结果。
- 上游变量使用单选Tree；改显示名称后关联稳定，删除来源产生可定位诊断。
- Frame移动保持成员相对位置，删除默认解组；Note不承担执行或讨论语义。
- 版本/大小/ID/端口/引用错误在替换前拒绝；未知类型保留原数据；导出先脱敏，不带执行输出。
- 只读检查按钮、拖动、菜单、键盘、配置、注释和导入；允许浏览与导出。
- 390/1024/1440px、粗指针、深浅主题、减少动态效果；连接有44px表单替代，图缩放后的端口不能成为唯一触屏路径。
- 五种数据态与已有图刷新失败；本地修改离开提醒；下载发起不等于持久化完成。
- 分发必须包含安装后的实际新增、连接、撤销浏览器证明；50/200节点分别记录实测条件，不把暖切换或UI夹具当成冷启动或真实服务验收。

- 权威运行快照拒绝旧run/版本/sequence，事件稳定ID去重；旧版本调试标记，当前画布不叠加旧执行。
- 停止等待最终确认，审批显式且防重复；响应丢失先查询，断线重读保留数据，输出与复制均脱敏/有界。
- 嵌套子流程进出保留选择/视口，边界方向类型与跨图变量校验；递归拒绝，普通图回路仍拒绝。
- 条件/Schema/键值配置实际应用并可撤销；已提交草稿不会在撤销后复活，无效草稿保留。
- 保存期间编辑仍dirty，CAS冲突保留草稿，unknown跨面板重挂载仍阻止写；版本恢复明确确认，发布未知先查询。
- 独立安装后的子流程导航和高级配置应实际可用；冷导航、暖切换、Inspector p95与拖动rAF分别记录。
